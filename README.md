# meowation

> A customizable cat avatar generator.

Mix and match bases, patterns, items, and colors to create your unique cat avatar.
Share it with a URL or export it as a PNG.

## Features

- **Base**: Choose a cat body shape
- **Patterns**: Layer fur patterns on top of the base
- **Items**: Add accessories and decorations
- **Colors**: Customize each body part's color
- **Share**: Copy a URL that recreates your avatar exactly
- **Export**: Download your avatar as a PNG image

## How to Use

1. Select a **base** from the panel
2. Toggle **patterns** and **items** to layer them on
3. Pick a **body part** and adjust its **color**
4. Hit **Share** to copy a shareable URL, or **Export** to download a PNG

## Tech Stack

React Router 8 · Cloudflare Workers · Tailwind CSS
